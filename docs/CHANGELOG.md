# Changelog

## 0.1.0 — Initial functional release

- Added modular resource collectors, system scoring, rule diagnostics, log analysis, anomaly and alert generation.
- Added validated YAML settings, SQLite event history, JSON/HTML/CSV exports, Typer CLI, and FastAPI routes.
- Added automated unit, API, and CLI coverage plus GitHub Actions checks.
